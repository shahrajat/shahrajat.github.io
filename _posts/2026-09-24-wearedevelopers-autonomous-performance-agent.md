I spoke at [WeAreDevelopers World Congress 2026 North America](https://www.wearedevelopers.com/) about "The Autonomous Performance Agent: A Netflix Production Story."

The talk is about an autonomous agent we built at Netflix that continuously profiles live services and proposes validated code fixes. Instead of waiting for someone to notice an inefficiency in a flamegraph, the agent finds it in production, traces it back to the code, and only suggests a fix once it has been validated - so performance problems get caught before they pile up or ship.

You can [watch the recording here](https://www.wearedevelopers.com/videos/100585-the-autonomous-performance-agent-a-netflix-production-story). It's part of the "AI agents in production" playlist.
