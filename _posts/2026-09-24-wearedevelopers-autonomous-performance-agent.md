I gave a talk at the WeAreDevelopers World Congress 2026 North America on September 24. It was called "The Autonomous Performance Agent: A Netflix Production Story."

The talk is about an agent we built at Netflix that keeps profiling live services in production and proposes code fixes for the inefficiencies it finds. Each fix is validated before it goes out, so the goal is to catch wasted CPU and slow code early instead of letting it sit in production for months.

You can watch the recording on the [WeAreDevelopers site](https://www.wearedevelopers.com/videos/100585-the-autonomous-performance-agent-a-netflix-production-story).
